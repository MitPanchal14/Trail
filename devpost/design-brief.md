# Design brief

## Retained baseline

The user selected the currently available 01b demo as the sole UI source for this repository cleanup. Its three runtime files are retained byte for byte under demo/. This selection supersedes old pixel-mountain layouts and competing historical proof folders. It does not certify every detail as final.

## Visual intent

Aim for Stripe/Linear-inspired clarity: generous but purposeful spacing, crisp type, strong next-action hierarchy, white/near-white surfaces and dark readable text, with selective blue/violet/cyan gradients. Colour should be composed rather than applied to every block. Dark mode needs deliberate contrast and surface separation. Smooth ambience should be soft and optional. Interactive elements need visible hover, focus and pressed states; never make essential information depend on hover.

Use actual saved work as the first focal point. Avoid decorative graphics that look like default generated illustrations, excessive cards, disconnected buttons or ambiguous slider-like decoration. Progress is secondary to continuing work. Design reference screenshots are in references/.

## Requested refinements still pending

Earlier feedback requested a more minimal landing without the milestone illustration, better dark styling, removal of the decorative Focus rail and an immediate compact completion dialog with finite ribbons. Those changes existed in an unpushed later proof and are not part of the retained 01b source. Do not claim they are implemented or restore that proof automatically. Future visual changes require an explicit bounded task against this baseline.

Do not recreate the rejected old working-app UI during functional development. Adapt real inputs to this retained composition. Confirm the exact journey treatment before redesigning it.
