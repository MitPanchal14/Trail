## Setup

Run Node20+ `npm run dev`, or use the approved final HTTPS origin after deployment. `npm run build` produces `dist/`. No package installation or account is needed for the application. Use Chrome as the primary target. Verify IndexedDB and Web Locks are available before recording; see DEPLOYMENT_PREFLIGHT.md. Localhost records do not transfer to a hosted origin.

Create this goal through the UI:

- Goal: **Prepare the community workshop update**
- Finished means: **A short update explains what is ready, what is blocked and who needs to do what next.**
- Action 1: **Choose the three points volunteers need to know**
- Action 2: **Draft the update with clear next steps**
- Action 3: **Check names, facts and next-step owners**

The reference URL is `https://example.com/#project-update`. It is a safe placeholder, not a connected document. Say so on screen. Trail stores and opens the URL; it does not inspect its contents or know whether the user worked there. For a live real-document recording, the user can supply a public document they own and deliberately replace this reference, with no private text visible.

## Opening edit and reproducible sequence

For the video, open with an eight-second close view of the saved next move/campsite from this same staged task, labelled **A saved place to return to · staged demo**. Then cut to its creation and demonstrate how that saved place was produced. This is an editing preview, not a false first-use state. Keep form entry brief and reach the actual close/reopen sequence before one minute.

If a real public document owned by the user is available and they authorize its use, it makes the reference shot more concrete. Otherwise the placeholder stays labelled; never say Trail opened the draft when it only opened example.com.

1. Show the fresh home, then Start working/Create a goal. Enter the fields above and Save. The mountain has no checked actions and an expedition marker at the first action. The no-goal art was an illustration, not personal progress.
2. Choose a 20-minute block and explicitly Start focus. Show a few seconds of the running timer. If performing the staged task, choose the three points in a separate scratch document; do not imply Trail can see it. Click Complete action when satisfied. The action checks immediately; the marker follows the route to action2. No waiting for the animation is required.
3. Explicitly Start focus on action2. Type a short draft in the separate scratch document. Pause. Save the next move **Under Next steps, add who will confirm the room booking. Then reread the opening.** Expand the optional extras. Where stopped: **Activities and volunteer roles are drafted. The room is still unconfirmed.** Work link: the placeholder above. Save my place.
4. Show the stopped campsite. Close the Trail tab, then reopen the same origin in the same profile. A short on-screen cut may say **Later — same browser and site**; do not alter a clock or pretend minutes passed. Show the saved next move and context. Timing is paused and no away time was credited.
5. Click Open work. Show the new tab and its placeholder status briefly; return to Trail. The timer remains stopped. Click Resume focus explicitly. The campsite becomes an expedition marker when the mountain is next viewed while running; Resume earns no checked action. Finish the staged draft and Complete action.
6. Start action3, review the staged wording, then Complete action. Review opens immediately. Show **All actions checked** / **Ready for review**: the goal is still open and the marker is below the summit. Confirm goal finished only when the definition is satisfied. The one dismissible reward shows summit arrival. Dismiss it.
7. Revisit Finished work, expand saved action/context details and briefly reload. The goal and notes remain; travel/reward does not replay. End on the kept mountain. Do not click Send in another app or claim the update was delivered.

Use live UI for every save/reload/completion. Typing and separate-document work can be shortened with visible **typing shortened** / **work interval shortened** cuts. Never speed up a focus clock to imply an actual 20-minute block.
